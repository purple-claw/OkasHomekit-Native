First-time setup

Create the OKAS owner account. The owner uses this email and password in the mobile app. The password is stored salted and scrypt-hashed on the board — the actual value never leaves the device.

Must be 8–128 characters with at least 3 of: lowercase, uppercase, digit, symbol.
